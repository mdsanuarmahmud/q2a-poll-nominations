# Q2A Poll Plugin

🗳️ A plugin inspired by the Indian Election System, built for [Question2Answer (Q2A)](https://www.question2answer.org/) platform.

## Features

- ✅ **Poll Creation**: Admins (or higher-level users) can create polls.
- 🧾 **User Nominations**: Users can nominate themselves for a poll during the **Nomination Period** (if enabled).
- 🗳️ **Voting**: All users can vote during the **Polling Period**.
- 📊 **Poll Stats**: Users can view poll options and nomination stats.
- 🎯 **Point Restrictions**:
  - Set minimum points required for **nominations**
  - Set minimum points required for **voting**
- 🔘 **Selection Type**:
  - Admins can configure polls for **single selection** or **multiple selection**
- ⚙️ **Nomination Control**:
  - Admins can choose whether to allow user nominations or not.
  
  
Pages in the Plugin:
1. create-poll - To create a new poll
2. update-poll - To update an existing poll. URL: update-poll&poll=
3. user-nomination- To register participation in a poll. URL: nomination&poll=
4. casting - To cast vote in the poll. URL: casting&poll=
5. list-polls - To list the available and completed polls
6. poll-stats - To show the stats of a poll
